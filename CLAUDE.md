# Couch Clash – rules for contributors and agents

- **Release notes:** Every pull request that changes something visible for players or hosts adds or updates an entry in `apps/web/src/content/changelog.ts` – German, for players, fun and non-technical (see the examples in the file). Bump the version: new feature → minor, fixes only → patch.
- The web app uses a new Next.js version – read `apps/web/AGENTS.md` before changing it.
